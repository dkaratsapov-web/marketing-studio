## Статистика рекламы в кабинете

Решение владельца от 17.10.2026, действует для всех проектов:
- из Яндекс Метрики берём только визиты, которые **автоматическая модель атрибуции** относит к Яндекс Директу
  (`attribution=automatic`, фильтр `ym:s:<attribution>AdvEngine=='ya_direct'`, константа `METRIKA_DIRECT_ONLY`
  в `crm/src/adstats/yandex.js`). Визиты, отказы, цели и срезы Метрики считаются только по ним;
- конверсии Директа — тоже по автоматической атрибуции (`AttributionModels: ['AUTO']`);
- расход из Директа — всегда с НДС (`IncludeVAT: 'YES'`), в интерфейсе подписывается «с НДС».
Не добавлять в статистику рекламы весь трафик сайта и не менять модель атрибуции без решения владельца.
