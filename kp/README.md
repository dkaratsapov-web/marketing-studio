# Коммерческие предложения

Исходники КП Корпорации. Ключей и паролей здесь не держим.

Каждое КП — своя папка: генератор (HTML → PDF через Playwright), картинки и готовый PDF.
Шрифты и знак берутся из сборки сайта, поэтому перед запуском нужен `npm run build`.

```bash
npm run build && (cd out && python3 -m http.server 8088 &)
node kp/kp-69-karkas-komfort/kk.cjs /путь/к/папке/для/pdf
```

Генератор сам проверяет, что ничего не вылезает за страницу, и рядом с собой кладёт снимки страниц `k-*.png`.

| КП | Клиент | Что |
|---|---|---|
| `kp-69-karkas-komfort` | «КаркасКомфорт» | Продвижение на Авито, VK, Сбер, MAX и Telegram: слайд на каждую площадку с таргетингами, настройками, цифрами аудитории и макетом объявления; бюджет и ведение по площадкам |
